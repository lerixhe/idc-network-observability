## A · 术语表

按出现顺序整理，只收本书用到的。

| 术语 | 一句话解释 |
|---|---|
| IDC | 数据中心。本书指以通用服务器与以太网为主体的传统机房 |
| TOR | Top of Rack，机柜顶上的接入交换机 |
| Spine | 骨干层交换机，连接大量 TOR |
| ECMP | 等价多路径，多条路径按哈希分摊流量 |
| 五元组 | 源 IP、目的 IP、源端口、目的端口、协议，哈希的输入 |
| PingMesh | 在全网服务器之间铺满主动探测，用完整矩阵衡量网络质量 |
| 微突发 | 持续毫秒级、峰值远超均值的流量突发 |
| 带内遥测（INT） | 让数据包自己携带路径上每一跳的元数据 |
| 光模块劣化 | 收发功率下降、误码上升的渐进过程，通常先表现为时延抬升 |
