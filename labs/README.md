name: IDC 网络可观测入门 · Labs

> 一本书的实验环境：Go 1.22 足矣，不需要特权，不需要外网。

## 用法

每个 lab 是一个独立 Go module，各自能跑：

```bash
cd labs/01-portstate
make run
```

一次性检查全部：

```bash
./scripts/check-labs.sh   # 逐个 go vet + go test
```

## 实验清单

| 实验 | 对应章节 | 做什么 |
|---|---|---|
| `00-setup` | 15（第一个探针） | 并发打点、算 p50/p99、样本落成 JSONL |
| `01-portstate` | 04–07 | 端口 down 的六成因判定树，输出成因、归属与下一步；样本混了 admin shutdown、单向链路、SNMP 代理重启三类陷阱 |
| `02-device-alive` | 08、09 | 一万台设备存活监测模拟：探测调度、去抖、探测侧故障识别、上下线事件；四类剧本各自的误报代价写在 README 里 |
| `03-probe-matrix` | 10、11、14 | 探测矩阵生成 + 健康评分：同机架不探、上行必探、层间抽样；把探针侧异常与网络侧异常分开 |
| `04-ecmp-hash` | 12 | 五元组哈希与路径覆盖：固定五元组 / 随机源端口 / 端口段预算三种策略的覆盖率曲线 |
| `05-int-sim` | 13 | INT 逐跳数据还原：时延分解、排队归因、部分覆盖时的盲区区间 |
| `06-snmp-walk` | 16、17、19 | 内置 agent 按列遍历 `ifTable` + `ifXTable`，四档限流排队不丢；样本含响应慢、不可达、换板后 `ifIndex` 重排 |
| `07-counters` | 18、36 | 三个版本的速率算法同场对比，样本埋 1G/10G 回绕、重启清零、漏采、乱序；错包四类归因 |
| `08-flow` | 20–22 | 解析 sFlow 与 NetFlow v9（模板过期/缺失/长度不符三种不可信段），模拟三档采样下的 TopN 失真 |
| `09-cmdb` | 23–26、28 | 脏台账对账：僵尸 / 幽灵 / 错挂三类差异，带置信度与纠正建议；补丁默认 dry-run，台账永不被改写 |
| `10-topology` | 26、29 | 四源拓扑融合（LLDP 为准、STP 校验、MAC 只打问号）与四源事件去重（211 条压到 12 条） |
| `11-endpoint` | 27 | IP → MAC → 交换机端口 → 机柜联查，三个陷阱各自带标记（MAC 漂移、聚合口只报逻辑口、租约在现网未见） |
| `12-task` | 30–32 | 拉取 vs 长连接的分发延迟对比（十万探针实跑 299ms）、四个失败模式的注入与检测，输出上报批次供 13 直接接 |
| `13-pipeline` | 33–35、37 | 编码开销 16.94×、双重幂等的点、四档水位线（窄了丢 9.36%，宽了多等 31 分钟）、三层保留容量估算 |
| `14-alert` | 38–40 | 父子抑制五道闸（87 条压到 5 条，收敛比 17.4:1）、血缘缺失的退化关联、三类规则命中对比 |
| `09-cmdb` | 23–26、28 | 脏台账对账：脏台账加 LLDP、ARP 两份快照，输出僵尸、幽灵、错挂三类差异并给出建议补丁；补丁不落库，dry-run 是默认 |

后续实验按 `drafts/book1/00-outline.md` 的实验矩阵逐个落地，编号与课文对得上。

## 留坑是设计的一部分

每个实验的样本都故意做过脏：`01-portstate` 里同一根纤两端判出不同成因，`02-device-alive` 里 CPU 打满的设备会被误判成重启，`09-cmdb` 里一台机器有两个名字、三台僵尸、两个幽灵。踩过一遍比看十遍正文管用——每个 lab 的 README 都有「这个实验故意留的坑」一节，做完再去对照。
